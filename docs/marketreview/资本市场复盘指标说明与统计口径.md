# 《每日市场复盘 Skill PRD》附录：指标说明与统计口径

## 1. 文档用途

本文档是《每日市场复盘 Skill PRD》的指标说明附录，用于统一总体复盘、每日梯队和情绪周期图的数据含义与统计口径。

本附录遵循以下原则：

- PRD 是产品范围、数据库设计和功能行为的依据；
- 本附录只解释指标，不另行扩展产品功能；
- 以交易日作为总体复盘和每日涨跌停事件的关联键；
- 未获取且用户未输入的数据保存为空值，展示时留空；
- 已确认的实际数值为 `0` 时保存并展示 `0`；
- 情绪周期图由总体复盘和每日涨跌停事件生成，不重复保存统计结果；
- V1 不处理午间数据、开盘数据和情绪周期阶段判断。
- 涨跌停与连板统计均排除 ST 股票，见第 2.1 节。

## 2. 总体复盘

### 2.1 复盘证券宇宙与 ST 排除

V1 涨跌停与连板的证券宇宙为上海、深圳、北京交易所上市的人民币普通股票。排除 B 股、ETF、基金、债券、可转债、退市整理股票、上市首日及当日无涨跌幅限制的股票；同时排除 ST 股票。

| 规则 | 说明 |
| --- | --- |
| 排除对象 | 交易日当日处于 `ST`、`*ST` 等特别处理状态的股票 |
| 每日涨跌停事件 | 有效涨停、20% 涨停、打开跌停、收盘跌停、涨停炸板对应的事件均不统计 ST |
| 首板与连板 | ST 股票不进入 `daily_price_limit_event`；上一交易日有效涨停分母也不统计 ST |
| 连板高度 | 只计算连续的、符合复盘证券宇宙条件的非 ST 涨停交易日 |
| ST 生效 | 股票进入 ST 状态时原连板连续性终止；撤销 ST 后再次涨停，重新从一板起算 |
| 历史判断 | 以对应交易日的历史状态为准，不得用当前名称或当前 ST 状态回填历史 |
| 实现建议 | 使用按交易日生效的 `is_st` 或证券状态字段，不依赖名称字符串 |

派生指标随之排除 ST：炸板率分子与分母、涨跌停比两侧、连板率分子与上一交易日有效涨停分母，均不含 ST。

市场宽度、成交额、市值、PE 等直接录入或全市场口径的指标，仍以证券软件展示为准；调用方提交涨跌停事件快照时，应按本条证券宇宙口径过滤。

### 2.2 基础字段

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 日期 | 数据所属的交易日，也是总体复盘与每日涨跌停事件的关联键；使用 `YYYY-MM-DD`。用户可在任意日历日发起复盘，但正式记录的业务日期必须是已收盘交易日；非交易日作为业务日期时不落库。 | 日期 |

### 2.3 涨跌停

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 有效涨停 | 统计涨停方向完整快照中 `closed_at_limit=true` 的事件。 | 整数，读时计算 |
| 20% 涨停 | 统计涨停方向完整快照中 `closed_at_limit=true and limit_rate_bp=2000` 的事件；北交所 30% 涨停不计入本项。 | 整数，读时计算 |
| 打开跌停 | 统计跌停方向完整快照中 `closed_at_limit=false` 的事件，即盘中曾触及跌停价但收盘未封在跌停价。 | 整数，读时计算 |
| 收盘跌停 | 统计跌停方向完整快照中 `closed_at_limit=true` 的事件。 | 整数，读时计算 |
| 涨停炸板 | 统计涨停方向完整快照中 `closed_at_limit=false` 的事件，即盘中曾触及涨停价但收盘未封在涨停价。 | 整数，读时计算 |
| 炸板率 | `涨停炸板数 ÷（涨停炸板数 + 有效涨停数）`；分子与分母均不含 ST。分母为 0 或组成数据缺失时留空。读时计算，不入库。 | 百分比，展示保留两位小数 |

事件记录存在即表示盘中曾触及对应方向的涨跌停价。北交所适用 30% 涨跌幅限制的非 ST 股票以 `limit_rate_bp=3000` 记录，并计入相应派生数量，但 V1 不单独展示 `30% 涨停`。盘中打开后重新封住且收盘仍为涨停或跌停时，分别归入有效涨停或收盘跌停。

涨停和跌停分别具有完整快照。无对应方向快照表示未知，指标留空；完整空快照表示该方向已确认零触板，对应数量为 `0`。

### 2.4 市场宽度

市场宽度覆盖上海、深圳和北京市场。上涨家数、下跌家数和中位数涨跌幅直接记录证券软件展示的数值，不由系统遍历全部股票重新计算。证券软件统计范围包含停牌和无成交股票。

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 回头波数 | 当日盘中最高价相对收盘价回落超过 10% 的股票数量，即 `最高价 ÷ 收盘价 - 1 > 10%`；V1 直接记录证券软件在上海、深圳和北京市场展示的数值，不强制与涨跌停的非 ST 证券宇宙一致。 | 整数 |
| 中位数涨跌幅 | 直接记录证券软件展示的全市场中位数涨跌幅；V1 作为手动输入项，未输入时留空。 | 百分比，展示保留两位小数 |
| 上涨家数 | 直接记录证券软件展示的当日上涨股票数量。 | 整数 |
| 下跌家数 | 直接记录证券软件展示的当日下跌股票数量。 | 整数 |
| 涨跌停比 | 使用“有效涨停数 : 收盘跌停数”的方向展示；两侧均不含 ST。由系统读取两项基础数据后计算，不单独保存。 | 比值 |

涨跌停比的展示规则：

- 两边均大于 0 时，将较小的一边归一化为 `1`，另一边保留两位小数；
- 有效涨停 58 只、收盘跌停 15 只，显示 `3.87:1`；
- 有效涨停 4 只、收盘跌停 15 只，显示 `1:3.75`；
- 两边相等，显示 `1:1`；
- 只有一边为 0 时保留实际数量，例如 `12:0` 或 `0:12`；
- 两边均为 0 时，两项基础数量显示 `0`，涨跌停比留空；
- 任一基础数据缺失时，涨跌停比留空。

### 2.5 连板

总体复盘中的首板与连板指标全部从连续交易日的完整涨停事件快照读时计算，不保存 `streak_height` 或重复汇总结果。只有 `direction=up and closed_at_limit=true` 的事件参与板数计算。

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 首板数 | 今日有效涨停、且上一交易日完整涨停快照中不存在同一股票有效涨停的数量。 | 整数 |
| 连板数 | 今日与上一交易日有效涨停股票集合的交集数量，即今日二板及以上股票数。 | 整数 |
| 连板率 | `今日连板数 ÷ 上一交易日有效涨停数`。今日与上一交易日涨停快照均须完整；分母为 0 或任一快照缺失时留空。上一交易日由 `packages/marketdata` 交易日历确定，不以库内前一条记录替代。 | 百分比，展示保留两位小数 |
| 最高板 | 对当日每只有效涨停股票逐交易日向前匹配完整涨停快照所得高度的最大值。 | 整数或空 |
| 最高板代表 | 当日达到最高连板高度的股票；同一高度存在多只股票时全部展示。 | 股票列表 |
| 1 至 10 板数量 | 按派生高度分别统计首板至 10 板的股票数量。 | 整数或空 |
| 11 板+数量 | 统计派生高度大于等于 11 的股票数量。 | 整数或空 |

今日涨停快照完整且为空时，有效涨停、首板、连板、最高板和各高度数量均为 `0`，最高板代表为空列表 `[]`。今日快照缺失时上述指标留空。

连板高度只计算连续的、符合证券宇宙条件的非 ST 涨停交易日。股票进入 ST 状态时原连续性终止；撤销 ST 后再次涨停，重新从一板起算。

每一个连续交易日都必须属于复盘证券宇宙并收盘涨停。停牌、收盘未涨停、进入 ST、进入退市整理期或出现无涨跌幅限制交易日，均中断连板。炸板后回封并以涨停收盘，仍视为当日涨停，连板可以延续。

只有在上一交易日涨停快照完整且未包含该股票有效涨停时，才能确认今日为首板。向前回溯遇到缺失快照时，该股票高度为未知；不得将未知高度写成 `1`。如果当日存在高度未知的有效涨停股票，依赖完整高度的最高板和梯队分布也应留空或明确标记不完整。

派生高度不限制在 11 板。总体复盘展示时 1 至 10 板分别成行，11 板及以上合并为 `11板+`；最高板仍展示实际高度。

## 3. 每日涨跌停事件与梯队

V1 保存所有符合口径且当日盘中曾触及涨停价或跌停价的股票。每日梯队从有效涨停事件派生，不另建连板明细表或重复分布表。

每只股票每个触板方向在一个交易日保存一条事件，使用“交易日期 + 市场 + 6 位代码 + 方向”作为唯一键。ST 股票及其他不符合复盘证券宇宙的记录不得写入事件表。

| 字段 | 统计口径 | 阶段 |
| --- | --- | --- |
| 交易日期 | 事件所属交易日。 | V1 |
| 市场 | 字段为 `market`，使用小写 `sh | sz | bj`，与 `packages/marketdata` 证券主数据一致。 | V1 |
| 股票代码 | 字段为 `code`，使用保留前导零的 6 位字符串；package 可返回 `<market>.<code>` 组合标识，展示仅显示 6 位代码。 | V1 |
| 股票名称 | 证券在该交易日使用的名称。 | V1 |
| 方向 | `direction=up` 表示曾触及涨停价，`down` 表示曾触及跌停价。 | V1 |
| 收盘状态 | `closed_at_limit` 表示收盘是否仍处于对应方向的涨跌停价格。 | V1 |
| 涨跌幅限制 | `limit_rate_bp` 按整数基点保存，10%/20%/30% 分别为 `1000/2000/3000`。 | V1 |
| 连板高度 | 不入库；对有效涨停事件按连续完整交易日快照读时派生。 | 派生 |
| 个股行情 | V2 按梯队产品需要补充；V1 不保存。 | V2 |
| 所属板块 | 股票所属板块。 | V2 |
| 炒作概念或涨停原因 | 当日对应的题材、事件或涨停原因。 | V2 |
| 昨日成交额 | 股票上一交易日的成交额。 | V2 |
| 开盘竞价额 | 股票当日集合竞价成交额。 | V2 |
| 竞价占比 | `开盘竞价额 ÷ 昨日成交额`；分母为 0 或缺失时留空。 | V2 |
| 昨日收盘价 | 股票上一交易日收盘价。 | V2 |
| 今日开盘价 | 股票当日开盘价。 | V2 |
| 开盘涨幅 | `今日开盘价 ÷ 昨日收盘价 - 1`。 | V2 |
| 当日成交额 | 股票当日全天成交额。 | V2 |
| 换手率 | 股票当日换手率。 | V2 |
| 是否龙头 | 是否为当日主线或题材龙头。 | V2 |
| 备注 | 对个股行情或人工判断的补充说明。 | V2 |

涨停炸板和跌停事件不属于连板梯队，但保留在相同事件模型中，可分别展示炸板、打开跌停和收盘跌停名单。V2 的行情特征和人工标注不应改变核心触板事实；必要时使用独立扩展对象。

## 4. 验收 fixture 要求

`2026-08-21` 已由仓库沪深交易日历确认为交易日，前一交易日固定为 `2026-08-20`。黄金 fixture 覆盖连续多个交易日的完整涨停快照、当日完整跌停快照、有效涨停、涨停炸板、打开跌停、收盘跌停、首板、连板和所有其他派生指标。

输入校验至少覆盖：重复事件、方向不一致、非法市场或代码、非法布尔值、非法涨跌幅限制、完整空快照、无完整快照时拒绝单股 patch，以及任一非法事件导致同次总体复盘 patch 全部回滚。另需覆盖历史涨停快照缺失时高度未知，不能误判为首板。

## 5. 情绪周期图

情绪周期图是跨交易日的展示视图，直接读取总体复盘和每日涨跌停事件，不单独保存重复结果。

| 展示指标 | 统计口径 |
| --- | --- |
| 日期 | 数据所属交易日。 |
| 最高连板高度 | 当日有效涨停事件的派生高度最大值。 |
| 最高板代表股票 | 当日达到最高连板高度的股票；同高度多只股票时全部展示。 |
| 有效涨停数量 | 统计当日涨停方向中收盘仍处于涨停的事件。 |
| 首板数量 | 统计派生高度为 1 的有效涨停事件。 |
| 连板数量 | 统计今日与上一交易日有效涨停股票集合的交集。 |
| 涨停炸板数量 | 统计当日涨停方向中收盘未封住的事件。 |
| 打开跌停数量 | 统计当日跌停方向中收盘未封住的事件。 |
| 收盘跌停数量 | 统计当日跌停方向中收盘仍处于跌停的事件。 |
| 各板高度数量 | 按交易日期和派生连板高度分组计数。 |

图表纵轴的连板高度根据查询区间内的实际最高连板高度动态生成，不受 11 板限制。
