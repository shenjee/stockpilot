# 《每日市场复盘 Skill PRD》附录：指标说明与统计口径

## 1. 文档用途

本文档是《每日市场复盘 Skill PRD》的指标说明附录，用于统一总体复盘、每日梯队和情绪周期图的数据含义与统计口径。

本附录遵循以下原则：

- PRD 是产品范围、数据库设计和功能行为的依据；
- 本附录只解释指标，不另行扩展产品功能；
- 以交易日作为总体复盘和连板个股数据的关联键；
- 未获取且用户未输入的数据保存为空值，展示时留空；
- 已确认的实际数值为 `0` 时保存并展示 `0`；
- 情绪周期图由总体复盘和每日梯队数据生成，不重复保存统计结果；
- V1 不处理午间数据、开盘数据和情绪周期阶段判断。
- 涨跌停与连板统计均排除 ST 股票，见第 2.1 节。

## 2. 总体复盘

### 2.1 复盘证券宇宙与 ST 排除

V1 涨跌停与连板的证券宇宙为上海、深圳、北京交易所上市的人民币普通股票。排除 B 股、ETF、基金、债券、可转债、退市整理股票、上市首日及当日无涨跌幅限制的股票；同时排除 ST 股票。

| 规则 | 说明 |
| --- | --- |
| 排除对象 | 交易日当日处于 `ST`、`*ST` 等特别处理状态的股票 |
| 涨跌停基础数量 | 有效涨停、20% 涨停、打开跌停、收盘跌停、涨停炸板均不统计 ST |
| 连板名单 | ST 股票不进入 `daily_ladder_stock`；上一交易日有效涨停分母和连板名单也不统计 ST |
| 连板高度 | 只计算连续的、符合复盘证券宇宙条件的非 ST 涨停交易日 |
| ST 生效 | 股票进入 ST 状态时原连板连续性终止；撤销 ST 后再次涨停，重新从一板起算 |
| 历史判断 | 以对应交易日的历史状态为准，不得用当前名称或当前 ST 状态回填历史 |
| 实现建议 | 使用按交易日生效的 `is_st` 或证券状态字段，不依赖名称字符串 |

派生指标随之排除 ST：炸板率分子与分母、涨跌停比两侧、连板率分子与上一交易日有效涨停分母，均不含 ST。

市场宽度、成交额、市值、PE 等直接录入或全市场口径的指标，仍以证券软件展示为准；用户录入涨跌停与连板名单时，应按本条证券宇宙口径填写。

### 2.2 基础字段

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 日期 | 数据所属的交易日，也是总体复盘与连板个股数据的关联键；使用 `YYYY-MM-DD`。用户可在任意日历日发起复盘，但正式记录的业务日期必须是已收盘交易日；非交易日作为业务日期时不落库。 | 日期 |

### 2.3 涨跌停

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 有效涨停 | 当日收盘仍处于涨停状态的股票数量；不含 ST 股票。上市首日及当日无涨跌幅限制的股票，V1 暂不计入。 | 整数 |
| 20% 涨停 | 创业板和科创板中，当日适用 20% 涨跌幅限制且收盘仍处于涨停状态的股票数量；不含 ST 股票。北交所 30% 涨停不计入本项。 | 整数 |
| 打开跌停 | 当日盘中曾触及跌停价、但收盘未封在跌停价的股票数量；不含 ST 股票。 | 整数 |
| 收盘跌停 | 当日收盘仍处于跌停状态的股票数量；不含 ST 股票。上市首日及当日无涨跌幅限制的股票，V1 暂不计入。 | 整数 |
| 涨停炸板 | 当日盘中曾触及涨停价、但收盘未能保持涨停的股票数量；不含 ST 股票。上市首日及当日无涨跌幅限制的股票，V1 暂不计入。 | 整数 |
| 炸板率 | `涨停炸板数 ÷（涨停炸板数 + 有效涨停数）`；分子与分母均不含 ST。分母为 0 或组成数据缺失时留空。读时计算，不入库。 | 百分比，展示保留两位小数 |

北交所适用 30% 涨跌幅限制的非 ST 股票计入相应的有效涨停、打开跌停、收盘跌停和涨停炸板基础数量，但 V1 不单独展示 `30% 涨停`。盘中打开后重新封住且收盘仍为涨停的股票计入有效涨停，不计入涨停炸板。

### 2.4 市场宽度

市场宽度覆盖上海、深圳和北京市场。上涨家数、下跌家数和中位数涨跌幅直接记录证券软件展示的数值，不由系统遍历全部股票重新计算。证券软件统计范围包含停牌和无成交股票。

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 回头波数 | 当日盘中最高价相对收盘价回落超过 10% 的股票数量，即 `最高价 ÷ 收盘价 - 1 > 10%`；V1 直接记录证券软件在上海、深圳和北京市场展示的数值，不强制与涨跌停的非 ST 证券宇宙一致。 | 整数 |
| 中位数涨跌幅 | 直接记录证券软件展示的全市场中位数涨跌幅；V1 作为手动输入项，未输入时留空。 | 百分比，展示保留两位小数 |
| 上涨家数 | 直接记录证券软件展示的当日上涨股票数量。 | 整数 |
| 下跌家数 | 直接记录证券软件展示的当日下跌股票数量。 | 整数 |
| 涨跌停比 | 使用“有效涨停数 : 收盘跌停数”的方向展示；两侧均不含 ST。由系统读取两项基础数据后计算，不单独保存。 | 比值 |

涨跌停比的展示规则：

- 两边均大于 0 时，将较小的一边归一化为 `1`，另一边保留两位小数；
- 有效涨停 58 只、收盘跌停 15 只，显示 `3.87:1`；
- 有效涨停 4 只、收盘跌停 15 只，显示 `1:3.75`；
- 两边相等，显示 `1:1`；
- 只有一边为 0 时保留实际数量，例如 `12:0` 或 `0:12`；
- 两边均为 0 时，两项基础数量显示 `0`，涨跌停比留空；
- 任一基础数据缺失时，涨跌停比留空。

### 2.5 连板

总体复盘中的连板指标全部从当日连板个股记录读时计算，不重复保存汇总结果。连板明细不含 ST 股票。

| 指标 | 统计口径 | 数据类型 |
| --- | --- | --- |
| 连板数 | 当日二板及以上股票的数量，即当日连板个股记录数；不含 ST。 | 整数 |
| 连板率 | `今日连板数 ÷ 上一交易日有效涨停数`；分子与分母均不含 ST。今日连板数直接统计 `daily_ladder_stock` 当日记录，无记录时为 `0`。分母只读上一交易日 `daily_market_review.effective_limit_up`；上一交易日由 `packages/marketdata` 沪深交易日历确定，不以库内前一条记录替代。该日复盘不存在、该字段为 `null` 或分母为 0 时留空。 | 百分比，展示保留两位小数 |
| 最高板 | 当日连板个股记录中 `streak_height` 的最大值。 | 整数 |
| 最高板代表 | 当日达到最高连板高度的股票；同一高度存在多只股票时全部展示。 | 股票列表 |
| 2 至 10 板数量 | 按 `streak_height` 分组后分别统计 2 至 10 板的股票数量。 | 整数 |
| 11 板+数量 | 统计 `streak_height >= 11` 的股票数量。 | 整数 |

当日无任何连板明细时，连板数、最高板和各高度数量均为 `0`，最高板代表为空列表 `[]`。

连板高度只计算连续的、符合证券宇宙条件的非 ST 涨停交易日。股票进入 ST 状态时原连续性终止；撤销 ST 后再次涨停，重新从一板起算。

每一个连续交易日都必须属于复盘证券宇宙并收盘涨停。停牌、收盘未涨停、进入 ST、进入退市整理期或出现无涨跌幅限制交易日，均中断连板。炸板后回封并以涨停收盘，仍视为当日涨停，连板可以延续。

数据库中的连板高度不限制在 11 板。展示时 2 至 10 板分别成行，11 板及以上合并为 `11板+`；最高板仍展示实际高度。

## 3. 每日梯队（连板个股明细）

V1 为计算总体复盘中的连板指标，只保存最小的连板个股记录。V2 在同一份记录上补充行情等字段并生成每日梯队，不另建重复的连板分布表。

每只连板股票在一个交易日保存一条记录，使用“交易日期 + 市场 + 6 位代码”作为唯一键。ST 股票不得写入本表。

| 字段 | 统计口径 | 阶段 |
| --- | --- | --- |
| 交易日期 | 记录所属交易日，与总体复盘日期一致。 | V1 |
| 市场 | 字段为 `market`，使用小写 `sh | sz | bj`，与 `packages/marketdata` 证券主数据一致。 | V1 |
| 股票代码 | 字段为 `code`，使用保留前导零的 6 位字符串。唯一身份为 `(market, code)`；package 可返回 `<market>.<code>` 组合标识，展示仅显示 6 位代码。 | V1 |
| 股票名称 | 证券在该交易日使用的名称。 | V1 |
| 连板高度 | 截至当日累计连续涨停的交易日数量；连板个股从二板开始记录；只计算非 ST 涨停交易日，见第 2.1 节。 | V1 |
| 是否 ST | 交易日当日的历史 ST 状态，字段为 `is_st`；本表只允许 `false`，`true` 的候选记录必须拒绝写入；不表示 V1 已接入历史 ST 数据源独立复核。 | V1 |
| 个股行情 | V2 按梯队产品需要补充；V1 不保存。 | V2 |
| 所属板块 | 股票所属板块。 | V2 |
| 炒作概念或涨停原因 | 当日对应的题材、事件或涨停原因。 | V2 |
| 昨日成交额 | 股票上一交易日的成交额。 | V2 |
| 开盘竞价额 | 股票当日集合竞价成交额。 | V2 |
| 竞价占比 | `开盘竞价额 ÷ 昨日成交额`；分母为 0 或缺失时留空。 | V2 |
| 昨日收盘价 | 股票上一交易日收盘价。 | V2 |
| 今日开盘价 | 股票当日开盘价。 | V2 |
| 开盘涨幅 | `今日开盘价 ÷ 昨日收盘价 - 1`。 | V2 |
| 当日成交额 | 股票当日全天成交额。 | V2 |
| 换手率 | 股票当日换手率。 | V2 |
| 是否龙头 | 是否为当日主线或题材龙头。 | V2 |
| 备注 | 对个股行情或人工判断的补充说明。 | V2 |

跌停股票不属于连板梯队。未来如需保存跌停股票明细，应使用独立的数据对象。

## 4. 验收 fixture 要求

`2026-08-21` 已由仓库沪深交易日历确认为交易日，前一交易日固定为 `2026-08-20`。该日黄金 fixture 覆盖全部原子指标、派生指标和空值/零值语义。fixture 中的涨跌停基础数量明确采用非 ST 口径，完整连板名单中不存在 ST 股票。

另设连板输入校验用例：向完整名单写入接口传入交易日有效状态为 `is_st=true` 的候选记录，系统必须原子地拒绝整次总体复盘 patch，列出问题股票代码并提示移除后重试，不得静默过滤。V1 只保存涨跌停聚合数量而不保存全部涨跌停个股明细，因此不虚构对 ST 涨跌停个股的库内二次过滤能力。

## 5. 情绪周期图

情绪周期图是跨交易日的展示视图，直接读取总体复盘和连板个股数据，不单独保存重复结果。

| 展示指标 | 统计口径 |
| --- | --- |
| 日期 | 数据所属交易日。 |
| 最高连板高度 | 当日连板个股记录中 `streak_height` 的最大值。 |
| 最高板代表股票 | 当日达到最高连板高度的股票；同高度多只股票时全部展示。 |
| 有效涨停数量 | 读取总体复盘中的有效涨停数。 |
| 连板数量 | 统计当日连板个股记录数。 |
| 收盘跌停数量 | 读取总体复盘中的收盘跌停数。 |
| 各板高度数量 | 按交易日期和 `streak_height` 对连板个股记录分组计数。 |
